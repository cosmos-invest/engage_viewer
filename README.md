# Engage Viewer 🌙

noteのスキ・記事コメント・フォロー通知をGmailから検索し、読者別の反応を手元のHTMLにまとめます。

## 実行

1. Google Cloudで Gmail API を有効化し、デスクトップ アプリ用の OAuth クライアントを作成。ダウンロードした JSON を `credentials.json` として置きます。OAuth がテスト中の場合は、自分の Gmail アドレスをテストユーザーに追加します。
2. Python 3.9 以上で次を実行し、note通知を受け取る Gmail アカウントで読み取り専用アクセスを許可します。

```sh
python -m pip install google-api-python-client google-auth-oauthlib
python engage.py --account YOUR_GMAIL_ADDRESS
```

生成した `engagement.html` をブラウザで開きます。全期間と直近30日を表示します。初回は対象通知を全件読み、再実行時は処理済み通知の結果を再利用します。メール本文とコメント本文は出力しません。

## 集計の定義

- スキとコメントは、読者ごとに異なる記事数で集計します。両方が同じ記事にあれば、反応記事数は1件です。王子本人、コメントへのスキ、コメントへの返信通知は除外します。
- 同じ記事の通知は、複数回届いても記事数に重複計上しません。本文から読者ID・記事IDを照合できない旧形式等の通知は、除外件数として表示します。
- フォロー通知は履歴です。現在のフォロワーの反応率を表示するには、現在のnote IDを1行ずつ並べたファイルを `--followers PATH` で渡します。未指定時は、フォロー通知で確認できた人の反応率を表示します。
- 反応率の分子は、期間内にスキかコメントをした該当者の人数です。無反応の閲覧や読了は計測できません。

OAuth 認証情報・キャッシュ・集計済みHTMLは手元に保存してください。
